Side effect, documented in the migration header: the global revoke covers functions
the postgres role creates in any schema. storage keeps its own per-schema grants.
Any other new postgres-created function (including one installed by an extension
run as postgres) needs an explicit GRANT EXECUTE. This is the same convention BF-60
set for tables and sequences.
