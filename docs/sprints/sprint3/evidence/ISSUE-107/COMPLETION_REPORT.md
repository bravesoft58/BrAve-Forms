## Feature Functionality

### Clone Modes

**1. Keep All Values (Default)**

- Description: "Copy all field values. Date, time, and signature fields will be reset."
- Behavior: Clones submission with most field values preserved
- Use Case: Similar inspection with some changes needed

**2. Structure Only**

- Description: "Keep form structure but clear all field values. Useful for creating a blank template."
- Behavior: Empty form with same structure
- Use Case: Want blank form of same type

**3. Clear All**

- Description: "Start completely fresh. Same template, no pre-filled values."
- Behavior: Completely clean slate
- Use Case: New inspection from scratch

### User Flow

1. User views submission detail page
2. Clicks "Use as Template" button
3. Dialog opens with 3 radio button options
4. User selects desired clone mode (default: Keep All Values)
5. User clicks "Create Template" button
6. Loading state shown ("Creating...")
7. On success: Dialog closes, navigates to form fill page with draftId
8. On error: Error message displayed in dialog with retry option

## Technical Implementation

### Component Architecture

**UseAsTemplateDialog.tsx:**

```typescript
interface UseAsTemplateDialogProps {
  submissionId: string;
  templateId: string;
  isOpen: boolean;
  onClose: () => void;
}

type CloneMode = 'keep_all' | 'structure_only' | 'clear_all';
```

**State Management:**

- `selectedMode` - useState for radio button selection
- `cloneMutation` - React Query mutation for API call

**Error Handling:**

- Mutation error displayed via Mantine Alert component
- User can retry without closing dialog

**Navigation:**

- On success: `router.push(\`/forms/\${templateId}/fill?draftId=\${data.id}\`)`
- Query cache invalidated for submissions list

### API Integration

**GraphQL Mutation:**

```graphql
mutation CloneSubmission($submissionId: ID!, $mode: String!) {
  cloneSubmission(submissionId: $submissionId, mode: $mode) {
    id
    templateId
    data
    status
    submittedAt
  }
}
```

**Authentication:**

- Uses `useAppAuth()` hook for token
- Fallback to 'dev-token-123' for development
