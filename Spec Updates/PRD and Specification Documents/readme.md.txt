# Project Name: Jobsite Logs Management App

## Overview
This app is designed to streamline the management of jobsite environmental logs (e.g., Dust Control, SWPPP) by providing a cloud-based solution for foremen and inspectors. Key features include:
- Log creation, editing, and copying.
- QR code access for inspectors.
- Customizable forms and templates.
- Multi-factor authentication (MFA).
- Role-based access control (RBAC).
